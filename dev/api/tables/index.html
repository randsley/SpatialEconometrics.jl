Coefficient tables and LaTeX / CSV / Markdown export.

SpatialEconometrics.SpatialTables.CoefTable — Type
CoefTable

A coefficient table ready for display or export, returned by coeftable.

Fields

  • names, estimate, std_error, z_stat, p_value: the usual columns.
  • ci_lower, ci_upper, ci_level: confidence interval bounds and the level they correspond to.

Export with to_latex, to_csv or to_markdown.

Note

Inference is normal-theory: z_stat and p_value use the standard normal, not a t distribution, which suits the large-sample maximum-likelihood estimators here.
