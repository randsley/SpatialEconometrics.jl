Panel Diagnostics

Hausman, Chow and joint LM tests for panels.

SpatialEconometrics.SpatialPanelDiagnostics.ChowTestResult — Type
ChowTestResult

Structural-break test over time for a spatial panel, returned by spatial_chow_test.

Fields: stat, df, p_value and break_period, the period tested. Rejection says the coefficients differ either side of that period, so a single pooled specification is not adequate.

source
SpatialEconometrics.SpatialPanelDiagnostics.HausmanTestResult — Type
HausmanTestResult

Fixed- versus random-effects test for a spatial panel, returned by spatial_hausman_test.

Fields: stat, df, p_value and the coefnames compared. Rejection favours fixed effects, because it says the unit effects are correlated with the regressors and the random-effects estimator is therefore inconsistent.

source
SpatialEconometrics.SpatialPanelDiagnostics.PanelLMTestResult — Type
PanelLMTestResult

Joint and individual LM tests for a spatial panel, returned by panel_lm_tests.

Carries a joint test (joint_stat, joint_df, joint_p) against the hypothesis of no spatial dependence and no random effects, plus the component tests: lag_stat/lag_p, error_stat/error_p and re_stat/re_p for the random-effects variance.

Read the joint test first; if it does not reject, the components are not worth chasing individually.

SpatialEconometrics.SpatialPanelDiagnostics.PanelMoranResult — Type
PanelMoranResult

Moran's I computed period by period for a panel, returned by panel_moran.

Fields: period_results, a vector of MoranResult with one entry per period; pooled; and T_periods.

pooled is not Moran's I of the stacked residuals. Its I_stat is the average of the per-period statistics and its z_stat is Stouffer's combination z̄ √T, computed from the per-period z values rather than from I_stat and Var_I. Both treat the periods as independent, which residuals from a single panel fit are not: they share β̂ and the fixed effects. Measured over 400 replications at N = 64, T = 5 on residuals from a correctly specified IndivFE SAR fit, the combined z has standard deviation 1.07 rather than 1.00 and rejects 6.5-7.2% of the time at the 5% level, so read it as mildly liberal. On genuinely independent draws it is accurate (standard deviation 0.95, rejecting 3.9%).

The per-period series is the useful part — it shows whether spatial dependence is stable over time or concentrated in particular periods, which a single pooled number hides.

SpatialEconometrics.SpatialPanelDiagnostics.panel_lm_tests — Function
panel_lm_tests(y, X, W, N, T)

LM tests for a spatial panel against a pooled OLS baseline: a spatial lag test, a spatial error test, a Breusch-Pagan test for random effects, and a joint test of all three.

The three component tests are each χ²(1). With A = I_T ⊗ W and τ = tr(A²) + tr(A′A) = T · (tr(W′W) + tr(W²)), the scores at the null are d_ρ = e′Ay/σ̂² and d_λ = e′Ae/σ̂², with

Var(d_λ) = τ,   Var(d_ρ) = Cov(d_ρ, d_λ) + τ = D,
D = (AXβ̂)′M(AXβ̂)/σ̂² + τ

so the lag test must be scaled by D, not by τ and not by the spread of the lagged observed y (Anselin 1988). The joint test is not the sum of the three components: d_ρ and d_λ are correlated, with Cov(d_ρ, d_λ) = τ, so their sum has variance above χ²(2). The spatial block uses the quadratic form in the inverse information instead (Anselin, Bera, Florax & Yoon 1996),

LM_spatial = [τ d_ρ² - 2τ d_ρ d_λ + D d_λ²] / [τ (D - τ)]

which is χ²(2). The random-effects score is a quadratic form in e whose cross-trace with A is tr(J_T ⊗ W) = T · tr(W) = 0, so it is asymptotically uncorrelated with both spatial scores and simply adds, giving a χ²(3) joint test.

Calibration

Under the null, 4000 replications at N = 64, T = 5 (Monte-Carlo standard error 0.34% on a rejection rate):

testmeanvariancerejects at 5%
lag1.0222.075.17%
error0.9982.335.40%
random effects1.0412.045.08%
joint3.0466.305.47%

Power at ρ = 0.15: 97.0% for the lag test, 89.9% for the joint test.

Note

Every statistic is clamped at zero, so a value of exactly 0.0 means the formula returned something negative and the test is uninformative, not that the null holds exactly.

SpatialEconometrics.SpatialPanelDiagnostics.spatial_chow_test — Function
spatial_chow_test(y, X, W, N, T, break_period)

Spatial Chow test for a structural break at break_period: an F test of whether the parameters are stable across the two sub-periods.

Each model is fitted by OLS on [X Wy], so the break restricts the K slopes and the spatial lag coefficient — K + 1 restrictions against 2(K + 1) unrestricted parameters, hence df = (K + 1, NT - 2(K + 1)). Counting only the K slopes roughly doubles the size of the test: over 1500 replications with no break at N = 64, T = 6, K = 3, the K-restriction version rejects 8.5-10.5% of the time at the 5% level and 1.8-2.7% at the 1% level, against 4.1-5.8% and 0.5-1.2% here (Monte-Carlo standard error 0.56%).

Note

Wy is endogenous, so the sub-period fits are not consistent estimates of a SAR and the F distribution is an approximation. The calibration above is the evidence that it is an adequate one at these sample sizes; it has not been checked for small N or for a weights matrix far from a lattice.

SpatialEconometrics.SpatialPanelDiagnostics.spatial_hausman_test — Function
spatial_hausman_test(m_fe, m_re; names=nothing)

Spatial Hausman test comparing two spatial panel estimators. Under H₀ the second model is consistent and efficient; under H₁ only the first is consistent, so a rejection favours m_fe.

Coefficients are matched by name, using the names the two models share, in the order they appear in m_fe. The names actually compared are returned in the result. Pass names to restrict the comparison to a chosen subset. The models should otherwise share the same dependent variable, covariates and W.

Matching by name matters. A NoFE panel fit carries an intercept that an FE fit does not, so the first position is the intercept in one model and the first slope in the other. Comparing those positionally builds a statistic out of unrelated parameters: it looks like a decisive rejection and means nothing.

When the statistic is not computable

The test inverts V(m_fe) - V(m_re), which the Hausman algebra requires to be positive definite — m_re must be the efficient estimator under the null. Passing the arguments the other way round inverts the ordering, and where there is a genuine efficiency ordering it leaves nothing to invert.

Directions whose eigenvalue is not clearly positive are dropped and df reports how many were kept, so df may be smaller than the number of names compared. If no direction survives, stat and p_value are NaN and df is 0: the two fits are not ordered by precision in any direction and there is nothing to compare. Check df before reading the p-value. The one exception is two fits with identical coefficients, where there is no difference to weigh and the result is stat = 0, p_value = 1, df = 0.

Both common fixed-effects pairings fail the null

Two fit_spatial_panel fits that differ only in their fixed-effects specification generally do not satisfy the efficiency condition, and this test is badly sized on them. Measured over 250 replications at N = 49, T = 5, ρ = 0.4, with the null true:

pairingresult
IndivFE vs TwoWayFE, no time effectsdegenerate: NaN in 160 of 250 draws, and 6 of the remaining 90 reject at the 5% level
NoFE vs IndivFE, effects uncorrelated with Xcomputable every time but oversized: 25.6% rejection at the 5% level

The first pairing is a near-cancellation — the two estimates differ by a standard deviation of 0.005 while each standard error is 0.037 — so V_fe - V_re is noise. The second is computable because an unmodelled individual effect inflates σ̂² and so every standard error in the NoFE fit, but that inflation comes from the misspecification itself rather than from an efficiency ordering, so the null distribution is not χ². It does have power — 100% rejection when the effects are correlated with X — but treat a borderline p-value from either pairing as uninformative.
