Short-T Dynamic Panel with Common Shocks

API reference for CommonShockDynamicPanel. See Short-T Dynamic Panel (Common Shocks) for the discussion, including the choice of the SERL order L.

Module

SpatialEconometrics.CommonShockDynamicPanel — Module
CommonShockDynamicPanel

Short-panel (fixed-T, large-N) dynamic spatial panel with common shocks, by Bai & Chen's (2026) conditional Gaussian QML with spatially enriched random loadings (SERL):

\[y_t = ρWy_t + φy_{t-1} + X_tβ + 1_Nδ_t + Λf_t + ε_t,\quad t = 1, …, T,\]

with r common factors f_t and loadings λ_i = Az_i + η_i. The controls z_i stack observed regressor summaries Q_X, the initial outcome y_0, and their spatial lags up to order L: z_i = [(Q_X)_i, (WQ_X)_i, …, (W^LQ_X)_i, (y_0)_i, …, (W^Ly_0)_i]. No unit-specific parameter is estimated, so T can stay fixed while N grows. The idiosyncratic variances σ²_t may change over time.

The likelihood is conditional on y_0. It is correct only when E(λ_i | y_0, X, W) = Az_i for the chosen L (Bai & Chen's Assumption 2). If y_0 comes from a long-running spatial process, a finite L is an approximation; the paper's Table 4 shows L = 0 is inconsistent in that design, and measures L = 1 only at N ≤ 1000.

The covariance is the sandwich Ĥ⁻¹Ω̂Ĥ⁻¹. Ω̂ is built from the score contributions rearranged into a martingale-difference array (Appendix D, eq. 54), so it allows non-normal η_i and ε_i.

References

Bai, J., & Chen, J. C. (2026). Fixed-T dynamic spatial panel model with common shocks. arXiv:2608.22499v1 [econ.EM]. Preprint.

Estimation

SpatialEconometrics.CommonShockDynamicPanel.CommonShockDynamicPanelModel — Type
CommonShockDynamicPanelModel

A fit of the short-panel dynamic spatial panel with common shocks by fit_common_shock_dynamic_panel.

Fields

  • coef, coefnames: θ = (ρ, φ, β).
  • vcov: the θ block of the sandwich Ĥ⁻¹Ω̂Ĥ⁻¹, with the pair component of Ω̂ scaled by N/(N − p_α) (the paper's preferred version, eq. 23). This block equals the profiled covariance of §3.4.
  • vcov_uncorrected: the same without the N/(N − p_α) factor.
  • alpha, alphanames, vcov_alpha: the full parameter vector α = (ρ, φ, β, δ, vec A, vec F₂, vech Σ_η, σ²) and its sandwich covariance.
  • delta, A, F, Sigma_eta, sigma2: the nuisance estimates, with F = [I_r; F₂]. A's columns follow controlnames; the controls are centred and scaled before estimation, so A is in standard-deviation units.
  • loglik: the conditional quasi log-likelihood (17), without 2π terms.
  • converged, outer_iterations, newton_iterations, score_norm (the largest |∂ℓ/∂α|/N at the estimate).
  • N, T, r, L.

SpatialEconometrics.CommonShockDynamicPanel.fit_common_shock_dynamic_panel — Function
fit_common_shock_dynamic_panel(y, X, W, N, T_total; r, L = 1, Q = nothing,
                               controls = nothing, eigenvalues = nothing,
                               rho_bounds = (-0.995, 0.995),
                               varnames = nothing, max_outer = 300,
                               max_inner = 200, tol = 1e-8)

Bai & Chen's (2026) conditional QML for the short-panel dynamic spatial panel with r common factors and spatially enriched random loadings (see CommonShockDynamicPanel for the model).

Data

y and X are stacked as in fit_dynamic_spatial_panel: N units within each of T_total = T + 1 periods, period 0 first. Period 0 supplies y₀; X's period-0 rows are not used. X has no intercept: the time effects δ_t take its place.

Options

  • r (required): the number of common factors. The theory takes it as known and gives no rule for choosing it.
  • L: the SERL order, the highest spatial lag of Q_X and y₀ among the controls. Bai & Chen's Table 4 finds L = 0 badly under-covers when y₀ comes from a long-running process, and L = 1 near nominal at N ≤ 1000. This package's Monte Carlo finds coverage of ρ at L = 1 near nominal up to N = 4000 (see the manual page).
  • Q: the N × p regressor summaries Q_X. The default is each unit's mean of X over periods 1..T. The mean is enough only if E(λ_i | X_i) depends on X_i through it. When the regressors' deviations from the loadings are serially correlated, it is not, and β̂ is biased by an amount that does not shrink with N. Passing every period of X (Q = hcat(X_1, …, X_T), N × KT) removes that bias; see the manual page.
  • controls: an N × q matrix that replaces the SERL controls z_i entirely; L and Q are then ignored.
  • eigenvalues: the eigenvalues of W, if already known. Otherwise they are computed, at O(N³) cost. Pass them when fitting many panels on the same W.
  • rho_bounds: the search interval for ρ; I − ρW must be nonsingular on it.
  • max_outer, max_inner: the limits of the block-coordinate algorithm (§4); tol: the convergence criterion of the final Newton polish, on the largest |∂ℓ/∂α|/N.

Algorithm

Appendix C's start (per-period OLS, then principal components), then Algorithm 1: ECME and GLS updates given ρ, alternated with a scalar search in ρ. Newton steps on the full parameter vector then solve the first-order conditions to tol. If they are not solved, the fit throws.

Variance

Ĥ = −∇²ℓ(α̂) by automatic differentiation of the analytic score. Ω̂ is eq. (54): the outer products of the one-unit parts of the rearranged scores, plus the sum over all pairs of units of the pair terms' outer products. The pair part is formed from N × N matrices, so the variance costs O(TN³) time and about eight N × N matrices of memory.

Returns

A CommonShockDynamicPanelModel.
