GS2SLS / SARAR Panels

Instrumental-variables estimation of SARAR panels with endogenous regressors.

SpatialEconometrics.SpatialGS2SLSPanel.GS2SLSModel — Type
GS2SLSModel

A fitted GS2SLS / SARAR panel, returned by fit_gs2sls_panel. Implements the StatsAPI.RegressionModel interface.

Carries coef and vcov, both spatial parameters rho and lambda, sigma2, the over-identification statistic with its p-value (Sargan's, or Hansen's robust J when errors = :heteroskedastic; both are stored in sargan_stat and sargan_pval), the weight matrix, residuals, coefnames, the panel dimensions and errors, the error assumption it was fitted under.

Estimated by instrumental variables rather than maximum likelihood, which is what lets it handle endogenous regressors alongside spatial dependence and avoids assuming normal errors.

Note

Check sargan_pval before reading anything else. A small value says the instruments are rejected, and then the coefficients are not credible whatever their standard errors look like.

source
SpatialEconometrics.SpatialGS2SLSPanel.fit_gs2sls_panel — Function
fit_gs2sls_panel(fe_spec, W, X_exog, X_endog, Z_iv, y, N, T_total;
                 varnames, exog_names, endog_names, errors = :homoskedastic)

Fit a SARAR panel with endogenous regressors by generalized spatial two-stage least squares.

Handles two problems at once: spatial dependence in both y and the errors (as in SARAR), and regressors correlated with the error for non-spatial reasons. Because it is an IV method it needs no distributional assumption, unlike the likelihood-based panel estimators.

Arguments

  • fe_spec: a FixedEffectsSpec.
  • W: N x N cross-sectional weight matrix.
  • X_exog: exogenous covariates.
  • X_endog: endogenous regressors.
  • Z_iv: excluded instruments — at least as many columns as X_endog, or the model is not identified.
  • y: stacked response.
  • N, T_total: units and periods; one period is consumed, so estimation uses T_total - 1.

Keywords

  • varnames, exog_names, endog_names: names for the output table.
  • errors: :homoskedastic (default) or :heteroskedastic. The default estimates λ from Kelejian & Prucha's (1998) moments, which assume every unit's errors have the same variance. :heteroskedastic uses their 2010 moments, which do not, and reports a covariance robust to unequal variances; see below.

Returns

A GS2SLSModel.

Warning

Same stacking convention as the other panel estimators: units vary fastest within each period. And read sargan_pval first — rejected instruments invalidate the estimates.

Examples

m = fit_gs2sls_panel(TwoWayFE(), W, X_exog, X_endog, Z_iv, y, N, T_total)
m.sargan_pval
m.rho, m.lambda

# Errors whose variance differs across units:
m = fit_gs2sls_panel(TwoWayFE(), W, X_exog, X_endog, Z_iv, y, N, T_total;
                     errors = :heteroskedastic)

A formula interface is available, which derives N, T_total and the stacking order from the table:

fit_gs2sls_panel(
    @formula(y ~ x1 + endo(x2, z1 + z2) + fe(region) + fe(year)),
    table, W; panel = :region, time = :year)

See also endo, extract_panel_permutation.

Identification

The design has to have full column rank, and the matrix checked is the within-transformed one, since that is what gets solved. Under IndivFE a regressor that does not vary over time is swept out entirely, and under TimeFE one that does not vary across units is; neither coefficient can be estimated from the within variation, and both now throw an ArgumentError naming the column instead of returning a number. The same applies to any covariate that is a linear combination of the others.

The excluded instruments are checked the same way, and before H is assembled — inv(H'H) comes first and would otherwise fail there.

The assembled instrument matrix H = [X, WX, W²X, Z, WZ] itself keeps only its linearly independent columns, as Kelejian & Prucha specify. With an intercept and a row-standardised W, WX repeats the intercept; that repeat used to make H′H singular, so an intercept under NoFE() could not be fitted.

Unequal error variances: errors = :heteroskedastic

The default λ̂ rests on E[ε′ε] = nσ² and E[ε′W′Wε] = σ²tr(W′W), which hold only if every variance is σ². When the variance moves with a unit's place in W (with its neighbour count, say), λ̂ is biased and its standard error is wrong. Kelejian & Prucha (2010) replace those moments with two built on zero-diagonal matrices, W′W − diag(W′W) and W, whose expectations are zero whatever the variances.

The fit then runs in three steps: 2SLS and an initial λ; GS2SLS at that λ, which gives θ̂ = (ρ̂, β̂); and λ̂ from the GS2SLS residuals, by GM weighted by the inverse of the moments' estimated covariance. That covariance includes the term the paper derives for residuals that carry θ̂'s estimation error, which Wy among the regressors makes first-order. The covariance of (θ̂, λ̂) is the paper's, including the θ̂–λ̂ block, with every sum taken by unit so that it is also robust to the serial correlation the fixed-effects transform introduces. The over-identification test is Hansen's J, computed at the efficient two-step GMM fit of the filtered model; it is stored in sargan_stat and sargan_pval.

Kelejian & Prucha's theory is for a cross-section, which here is NoFE() with T_total = 2, since the first period is dropped. Pooling the moments over periods on within-transformed data is this package's extension. Time demeaning correlates units at O(1/N), and that is ignored.

Measured (validation/mc_gs2sls_het.jl, 2,000 replications per cell, AUDIT finding 36), error sd proportional to the neighbour count on an irregular map, against constant sd; hom is the default, het is errors = :heteroskedastic.

With constant variance the two agree. Under TwoWayFE λ̂ is about 0.03 low on both paths. At N = 300 both paths under-cover ρ (0.70–0.89), and at λ = 0.8 the over-identification test over-rejects (0.18–0.21). That is the sample size, not the variances.

W must have a zero diagonal, or the fit throws: the moments are valid for any variances only because the diagonal is zero.

Under either setting the coefficients' covariance is clustered by unit, and σ̂² uses the degrees of freedom the within transform leaves. Until AUDIT finding 36 the default used HC0 and the mean squared transformed residual. In six-period panels with constant variance its intervals then covered at 0.89–0.92, and Sargan's test rejected 13% of true nulls.
