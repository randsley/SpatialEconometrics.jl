Weight Matrices

Constructing, standardizing, inspecting and reading weight matrices.

SpatialEconometrics.SpatialWeights.SpatialConnectivity — Type
SpatialConnectivity

Summary of a weight matrix's structure, returned by spatial_connectivity. Worth looking at before fitting anything.

Fields

  • N, n_nonzero, density: size and sparsity.
  • avg_neighbors, min_neighbors, max_neighbors: the degree distribution.
  • n_islands: units with no neighbours at all.
  • is_symmetric: whether W == W'. Row-standardizing a symmetric contiguity matrix generally destroys symmetry, so false here is normal and not a problem.
  • spectral_radius: largest eigenvalue magnitude; 1 for a row-standardized matrix.
Warning

n_islands > 0 deserves attention. An isolated unit contributes nothing to the spatial likelihood and its row of W*y is zero, so it is effectively dropped from the spatial part of the model while still counting towards N.

SpatialEconometrics.SpatialWeights.distance_weights — Function
distance_weights(coords, cutoff; decay=:inverse, alpha=1.0, row_standardize=true)

Build distance-decay spatial weights. Pairs beyond cutoff get zero weight.

Decay functions:

  • :inverse — 1 / d^alpha
  • :negative_exponential — exp(-alpha * d)
  • :power — d^(-alpha) (same as inverse, explicit name)
  • :bisquare — (1 - (d/cutoff)^2)^2

SpatialEconometrics.SpatialWeights.minmax_standardize — Function
minmax_standardize(W) -> SparseMatrixCSC

Copy of W divided by the smaller of its largest row sum and largest column sum. See minmax_standardize! for the in-place version.

A middle course between row_standardize and spectral_standardize: it keeps relative connectedness while being cheaper than an eigenvalue computation, which matters for large W.

SpatialEconometrics.SpatialWeights.order_weights — Function
order_weights(W, l; row_standardize = true, binary = true)

The order-l spatial weights matrix: unit j is a neighbour of i iff the shortest path from i to j in W's adjacency graph has exactly l steps. l = 0 returns the identity.

This is the W⁽ˡ⁾ of Anselin & Smirnov (1996), and it is not W^l.

`W^l` is a different object

W² counts walks of length two, so it is non-zero on the diagonal — every i reaches itself back through any neighbour — and it double-counts units reachable by several two-step paths. order_weights(W, 2) instead partitions the pairs: each j appears at exactly one order, its shortest-path distance, and the diagonal is empty for l ≥ 1.

Measured on a 4×4 rook lattice (N = 16, 48 first-order links): W² has 84 non-zeros, 16 of them on the diagonal, against 68 and 0 for order_weights(W, 2). Summed over orders 1 to 6 — 6 being the lattice's diameter — order_weights yields exactly N(N−1) = 240 ordered pairs, each once.

W² also retains first-order neighbours wherever a triangle exists, which order_weights never does. On a triangle with one pendant unit, W² is non-zero on 6 pairs that are already first-order neighbours; order_weights(W, 2) is non-zero on 0.

The construction is a breadth-first search from each unit, so the cost is O(N·nnz(W)) and the result depends only on W's sparsity pattern, not on its values — any row-standardisation already applied to W is irrelevant to which pairs come out at which order.

Pass binary = false to weight each order-l link by 1/d where d is the number of distinct shortest paths; the default true gives the usual binary-then-row-standardised contiguity matrix.

Arguments

  • W: the first-order weights or adjacency matrix, N×N. Only its pattern is read.
  • l: the order. 0 gives I; l greater than the graph diameter gives an all-zero matrix, which order_weights_list refuses rather than returning.

See also order_weights_list, which returns [W⁽⁰⁾, …, W⁽ˢ⁾] and checks the diameter once for the whole list.

SpatialEconometrics.SpatialWeights.order_weights_list — Function
order_weights_list(W, s; row_standardize = true, binary = true)

[W⁽⁰⁾, W⁽¹⁾, …, W⁽ˢ⁾] with W⁽⁰⁾ = I, each built by order_weights.

Refuses when s exceeds the graph diameter, rather than returning an all-zero matrix for the orders that do not exist: a model fitted with an empty W⁽ˡ⁾ has a structurally zero column, and the coefficient on it is not identified. The error reports the diameter so the caller can lower s.

A disconnected W has no finite diameter; the check is applied per component, so s may be at most the largest component's diameter and the orders remain well defined within components.

SpatialEconometrics.SpatialWeights.read_gal — Function
read_gal(path; ids=nothing) → (W, ids)

Read a GeoDa GAL contiguity weights file. Returns the row-standardized sparse weight matrix and the observation ID vector, where row i of W corresponds to ids[i].

The ordering comes from the file's observation records, in record order. Pass ids to impose an external table's ordering instead. A neighbour id with no observation record raises an error.

SpatialEconometrics.SpatialWeights.read_gwt — Function
read_gwt(path; ids=nothing) → (W, ids)

Read a GeoDa GWT (general weights) file. Returns the sparse weight matrix and the observation ID vector, where row i of W corresponds to ids[i].

A GWT file is only an edge list and carries no ordering of its own, so the ids found in it are sorted — numerically when they all parse as integers, else lexicographically. Pass ids to impose an external table's ordering instead.

SpatialEconometrics.SpatialWeights.row_standardize — Function
row_standardize(W) -> SparseMatrixCSC

Row-standardized copy of W: every row with at least one neighbour sums to 1. See row_standardize! for the in-place version.

This is the conventional normalization, and most of this package assumes it. It makes W*y a neighbourhood average, bounds the spatial parameter inside (-1, 1), and makes Moran's I equal the slope in a Moran scatter plot. Rows with no neighbours stay all-zero.

SpatialEconometrics.SpatialWeights.spectral_standardize — Function
spectral_standardize(W) -> SparseMatrixCSC

Copy of W divided by its spectral radius. See spectral_standardize! for the in-place version.

Bounds the spatial parameter in (-1, 1) as row-standardization does, but without rescaling rows relative to one another, so differences in connectedness between units are preserved. Preferable when the number of neighbours is itself meaningful; the cost is that W*y is no longer a simple neighbourhood average.
