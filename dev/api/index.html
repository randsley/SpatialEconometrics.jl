Panel Diagnostics

SpatialEconometrics.SpatialPanelDiagnostics.spatial_hausman_test — Function
spatial_hausman_test(m_fe, m_re; names=nothing)

Spatial Hausman test comparing two spatial panel estimators. Under H₀ the second model is consistent and efficient; under H₁ only the first is consistent, so a rejection favours m_fe.

Coefficients are matched by name, using the names the two models share, in the order they appear in m_fe. The names actually compared are returned in the result. Pass names to restrict the comparison to a chosen subset. The models should otherwise share the same dependent variable, covariates and W.

Matching by name matters. A NoFE panel fit carries an intercept that an FE fit does not, so the first position is the intercept in one model and the first slope in the other. Comparing those positionally builds a statistic out of unrelated parameters: it looks like a decisive rejection and means nothing.

SpatialEconometrics.SpatialRegimeModels.fit_spatial_regime — Function

Fit a spatial regime model where coefficients vary across regimes: y = ρWy + Xr βr + ε (spatiallag=true) y = Xr βr + ε (spatiallag=false)

Each regime gets its own intercept and slope coefficients. Anselin (1988, 1990).

source
SpatialEconometrics.SpatialRegimeModels.skater_regimes — Function
skater_regimes(W, X, n_regimes; min_size=1, rng=Random.default_rng())

Spatially constrained clustering via SKATER minimum spanning tree partitioning. Returns an ExogenousRegimes assignment with n_regimes contiguous groups, each guaranteed to be a connected region of W.

A minimum spanning tree is built over the contiguity graph with edge weights given by Euclidean distance between the standardised rows of X. The tree is then split n_regimes - 1 times, each time choosing the edge whose removal most reduces the within-group sum of squared deviations.

min_size is the smallest admissible region; cuts that would leave a smaller component are skipped. Raise it when the regions feed a regime regression, which needs enough units per region to identify its own coefficients.

Assunção et al. (2006) "Efficient regionalization techniques for socio‐economic geographical units using minimum spanning trees."

Discrete Choice

SpatialEconometrics.SpatialDiscreteChoice.fit_spatial_probit — Function
fit_spatial_probit(W, X, y; varnames=nothing, instrument_lags=2)

Fit the spatial autoregressive probit model

y* = ρWy* + Xβ + ε,    y = 1(y* > 0)

by the linearized GMM estimator of Klier & McMillen (2008). A standard probit supplies the ρ = 0 starting value; the moment conditions are then linearized around it and estimated by 2SLS with instruments [X, WX, W²X].

y must be coded 0/1. Returns a SpatialProbitModel.

Fitted probabilities use the heteroskedastic latent form Φ(((I-ρW)⁻¹Xβ)ᵢ / √[(I-ρW)⁻¹(I-ρW)⁻ᵀ]ᵢᵢ), which needs a dense inverse of I - ρW; cost is O(N³), so this is intended for moderate N.

loglikelihood reports the probit log-likelihood evaluated at the fitted index. It is a pseudo-likelihood — the estimator is GMM, not ML — so it is comparable across specifications fit the same way, but is not an ML criterion.

Linearizing around ρ = 0 buys speed at a real cost in efficiency. Over 8 replications at ρ = 0.4 this estimator had a standard deviation of about 0.25 at N = 196 and 0.18 at N = 400 — roughly 2.5× that of fit_bayesian_spatial_probit on the same data. It is approximately unbiased, so treat a single small-sample ρ̂ as a coarse reading and prefer the Gibbs sampler when precision on ρ matters.

source
SpatialEconometrics.SpatialDiscreteChoice.fit_bayesian_spatial_probit — Function
fit_bayesian_spatial_probit(W, X, y; n_samples=2000, burnin=500, rng=...)

Fit the spatial autoregressive probit by Gibbs sampling with Albert & Chib (1993) data augmentation, following LeSage & Pace (2009, Ch. 10).

Each sweep: draw the latent y* one site at a time from its truncated conditional, draw β from its conjugate normal conditional, then update ρ by random-walk Metropolis on log|I-ρW| - ½(Ay*-Xβ)'(Ay*-Xβ) with a Uniform(-1,1) prior. The error variance is fixed at 1 for identification.

beta_prior_var sets an isotropic N(0, v·I) prior on β. Reported coef and vcov are the posterior mean and covariance; accept_rate is the ρ acceptance rate, which should land roughly in 0.2–0.5. The default rho_proposal_sd of 0.2 targets that band; 0.05 overshoots to about 0.77 acceptance and mixes slowly.

Because the observed signs pin the latent vector only up to scale, ‖β‖ and ρ trade off along a weakly identified ridge. The posterior is still centred correctly — over 8 replications at ρ = 0.4 the posterior mean averaged 0.374 at N = 196 — but its spread is wide (SD ≈ 0.10), so a single chain at small N can sit well away from the truth. Check accept_rate and lengthen the chain before reading much into one ρ estimate.

source
SpatialEconometrics.SpatialDiscreteChoice.fit_spatial_ordered_probit — Function
fit_spatial_ordered_probit(W, X, y; n_categories=maximum(y), n_samples=2000, ...)

Fit the spatial ordered probit

y* = ρWy* + Xβ + ε,    y = j  iff  τ_{j-1} < y* ≤ τ_j

by Gibbs sampling with data augmentation (Wang, Kockelman & Wang, 2013). y holds integer categories 1:J.

For identification there is no intercept and τ_1 = 0; the free cutpoints τ_2 … τ_{J-1} are drawn from their uniform conditionals between the adjacent order statistics of the latent vector. τ_0 = -∞ and τ_J = +∞.

A binary y (J = 2) reduces to the probit above and is better served by fit_bayesian_spatial_probit, which carries an intercept.

source
SpatialEconometrics.SpatialDiscreteChoice.marginal_effects — Function
marginal_effects(m::SpatialProbitModel)

Decompose the marginal effect of each covariate into direct, indirect, and total components. For covariate k the effect matrix is diag(φ(index)) (I-ρW)⁻¹ βₖ; the direct effect averages its diagonal, the total averages its row sums, and the indirect effect is the difference (LeSage & Pace, 2009).

Requires a dense inverse of I - ρW — O(N³), so intended for moderate N.

Spatial Filtering

SpatialEconometrics.SpatialFiltering.SpatialEigen — Type
SpatialEigen

A screened eigenvector basis for spatial filtering, as returned by spatial_eigenvectors.

Fields

  • values::Vector{T}: eigenvalues of Ω = M Wᵤ M, in descending order.
  • vectors::Matrix{T}: the corresponding eigenvectors, one per column. Columns are orthonormal and each sums to zero.
  • moran::Vector{T}: each eigenvector's Moran coefficient, (N/S₀)λᵢ.
  • S0::T: the sum of all weights, Σᵢⱼ wᵢⱼ.
  • N::Int: the number of spatial units.

Pass an instance as the eigen_basis keyword of fit_esf or fit_re_esf to reuse one decomposition across several fits.

source
SpatialEconometrics.SpatialFiltering.spatial_eigenvectors — Function
spatial_eigenvectors(W; n_candidates=nothing, min_moran_ratio=0.0)

Eigendecomposition of the doubly-centred weight matrix Ω = (I - 11'/N) Wsym (I - 11'/N), following Griffith (2003).

The eigenvectors are mutually orthogonal and uncorrelated, and each carries Moran coefficient MCᵢ = (N/S₀)λᵢ. Eigenvectors with large positive eigenvalues describe positive spatial autocorrelation patterns; large negative eigenvalues describe negative ones. Results are sorted by eigenvalue, descending.

An asymmetric W (e.g. row-standardised) is symmetrised as (W + W')/2 so the eigenvalues are real.

The constant vector is removed by construction rather than by discarding an eigenvector afterwards: with Q an orthonormal basis of 1's orthogonal complement, Q'ΩQ = Q'WsymQ, so eigendecomposing the reduced (N-1)×(N-1) matrix and mapping back as E = QV yields vectors that are orthonormal and exactly mean-zero. Decomposing Ω directly would not: its null space is multi-dimensional, the solver may return any rotation within it, and the constant direction then smears across several near-zero eigenvectors that are each partly collinear with the intercept.

n_candidates keeps only the leading eigenvectors; min_moran_ratio keeps those with MCᵢ / max(MC) ≥ ratio, the usual screen for positive-SA filtering (0.25 is a common choice). Both are applied after sorting.

Dense eigen is O(N³) — intended for moderate N.

source
SpatialEconometrics.SpatialFiltering.moran_coefficient — Function
moran_coefficient(y, W)

Moran coefficient (N/S₀) · (z'Wz)/(z'z) for z = y - ȳ, where S₀ is the sum of all weights. The bare statistic with no inference — use SpatialDiagnostics.moran_global when you need a p-value.

SpatialEconometrics.SpatialFiltering.fit_esf — Function
fit_esf(X, y, W; family=:gaussian, max_eigenvectors=20, criterion=:moran, ...)

Eigenvector spatial filtering (Griffith, 2003). Selected eigenvectors of the doubly-centred W enter as extra regressors, absorbing the spatial autocorrelation so the remaining coefficients can be read as aspatial:

\[g(\mu) = \alpha + X\beta + E_{sel}\gamma\]

family is :gaussian (OLS), :poisson, :logit, or :negbin; the last three are fit by IRLS, with the negative binomial's dispersion updated by method of moments between IRLS passes (Chun et al., 2016). This makes ESF usable wherever a GLM is, which parametric SAR/SEM cannot match.

Eigenvectors are added greedily. criterion=:moran picks, at each step, the candidate that most reduces the absolute Moran coefficient of the residuals (Pearson residuals for GLM families); criterion=:aic picks the one that most reduces AIC. Selection stops at max_eigenvectors, when no candidate improves the criterion, or — under :moran — once |MC| falls below moran_tol.

min_moran_ratio screens the candidate pool to eigenvectors with MCᵢ/max(MC) ≥ ratio (default 0.25, the usual positive-SA screen). Pass a precomputed SpatialEigen as eigen_basis to reuse one decomposition across several fits.

Cost is O(max_eigenvectors × n_candidates) model fits, so keep the pool bounded for GLM families.

SpatialEconometrics.SpatialFiltering.fit_re_esf — Function
fit_re_esf(X, y, W; min_moran_ratio=0.25, n_candidates=nothing, varnames=nothing)

Random-effects eigenvector spatial filtering (Murakami & Griffith, 2015):

\[y = X\beta + E\gamma + \varepsilon, \quad \gamma \sim N(0, \tau^2\Lambda), \quad \varepsilon \sim N(0, \sigma^2 I)\]

Rather than selecting eigenvectors discretely, every positive-eigenvalue eigenvector is retained and its coefficient shrunk toward zero, with the shrinkage governed by the single variance ratio θ = τ²/σ² estimated by profile REML. This sidesteps the model-selection variance of stepwise ESF.

Because E has orthonormal columns, V = σ²(I + θEΛE') inverts in closed form — its eigenvalues are 1 + θλₗ inside span(E) and 1 outside — so each REML evaluation is O(NL), not O(N³). The decomposition itself is still O(N³).

Only positive-eigenvalue eigenvectors are used, the standard choice for positive spatial autocorrelation, and min_moran_ratio screens them further to MCᵢ/max(MC) ≥ ratio.

Reading the residual Moran coefficient

moran_final is the Moran coefficient of the conditional residual y - Xβ̂ - Eγ̂, and it is expected to be substantially negative — do not compare it against zero. Subtracting Eγ̂ removes the positively autocorrelated directions, leaving a residual that lives mostly in the orthogonal complement of span(E); a vector drawn at random from that complement has Moran coefficient

\[\frac{N}{S_0}\cdot\frac{-S_0/N - \sum_l \lambda_l}{N - 1 - L}\]

which is reported as moran_reference. On correctly specified data with N = 121 and L = 40 this reference is −0.304 and the fitted residual lands near −0.24, i.e. slightly less negative than chance. A moran_final close to or above moran_reference is the healthy case; one far below it suggests the random effects are absorbing noise, as does an edf (effective degrees of freedom, P + Σ θλ/(1+θλ)) approaching N.

SpatialEconometrics.SpatialSimulation.monte_carlo_spatial — Function
monte_carlo_spatial(dgp, W, N, K, estimator; config=MonteCarloConfig(), x_generator=nothing)

Run a Monte Carlo experiment. estimator is a function (W, X, y) -> model returning a StatsAPI.RegressionModel. Returns MonteCarloResult with bias, RMSE, and test rejection rates.

The DGPs generate y without an intercept while the estimators fit one, so a leading (Intercept) coefficient is dropped before comparison; the remainder lines up with the DGP's parameter ordering for all six DGPs.

Rows are labelled by the DGP, not the estimator

param_names comes from dgp, so the table is only fully meaningful when the estimator matches the DGP. Deliberately fitting a misspecified model still reports useful bias and RMSE for the β rows, but a trailing row labelled ρ or λ holds whichever parameter the estimator happens to return in that position — for an SLX fitted to SAR data, for instance, it is the W_x1 coefficient.

Replications whose estimator throws are excluded and reported rather than averaged in; n_successful records how many contributed.
