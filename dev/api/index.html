Weight Matrix Construction

SpatialEconometrics.SpatialWeights.knn_weights — Function
knn_weights(coords, k; binary=false, row_standardize=true, symmetrize=false)

Build a spatial weight matrix from k-nearest neighbors. coords is N×D (rows = observations). Returns a sparse N×N matrix.

source
SpatialEconometrics.SpatialWeights.distance_weights — Function
distance_weights(coords, cutoff; decay=:inverse, alpha=1.0, row_standardize=true)

Build distance-decay spatial weights. Pairs beyond cutoff get zero weight.

Decay functions:

  • :inverse — 1 / d^alpha
  • :negative_exponential — exp(-alpha * d)
  • :power — d^(-alpha) (same as inverse, explicit name)
  • :bisquare — (1 - (d/cutoff)^2)^2

Panel Diagnostics

SpatialEconometrics.SpatialPanelDiagnostics.spatial_hausman_test — Function
spatial_hausman_test(m_fe, m_re)

Spatial Hausman test comparing spatial FE and RE estimators. Under H₀ (RE is consistent), both estimators are consistent but RE is efficient. Under H₁, only FE is consistent.

Both models must have the same dependent variable, covariates, and W.

source
SpatialEconometrics.SpatialPanelDiagnostics.spatial_chow_test — Function
spatial_chow_test(y, X, W, N, T, break_period)

Spatial Chow test for structural break at break_period. Tests whether parameters are stable across two sub-periods. Uses the LR-based approach adapted for spatial models.

source
SpatialEconometrics.SpatialPanelDiagnostics.panel_lm_tests — Function
panel_lm_tests(y, X, W, N, T)

Joint LM tests for spatial panels (Baltagi, Song & Koh 2003). Tests simultaneously for spatial lag, spatial error, and random effects from a pooled OLS baseline. Returns individual and joint test statistics.

SpatialEconometrics.SpatialModelSelection.common_factor_test — Function
common_factor_test(coef_beta, coef_theta, rho, vcov_full)

Tests whether SDM simplifies to SEM, i.e. H₀: θ + ρβ = 0.

  • coef_beta: vector of K slope coefficients (excluding intercept)
  • coef_theta: vector of K spatial lag coefficients (WX terms)
  • rho: spatial autoregressive parameter
  • vcov_full: full variance-covariance matrix of [β; θ; ρ]

Uses the Wald test formulation from Burridge (1981).

source
SpatialEconometrics.SpatialModelSelection.wald_test — Function
wald_test(m, R, r)

General Wald test: H₀: Rβ = r.

  • R: Q×K restriction matrix
  • r: Q-vector of restriction values

Higher-Order Models

SpatialEconometrics.HigherOrderSpatial.fit_slx — Function
fit_slx(W, X, y; varnames=nothing)

Fit the SLX (Spatial Lag of X) model by OLS: y = Xβ + WXθ + ε

No spatial lag of y and no spatial error structure. Recommended as a starting point before SAR/SDM (Halleck Vega & Elhorst, 2015).

source
SpatialEconometrics.HigherOrderSpatial.fit_sac — Function
fit_sac(W_lag, W_error, X, y; varnames=nothing, method=ChebyshevApprox())

Fit the SAC (Spatial Autoregressive Combined) model via concentrated ML: y = ρW₁y + Xβ + u, u = λW₂u + ε

Also known as SARAR when W₁ = W₂. Kelejian & Prucha (1998).

source
SpatialEconometrics.HigherOrderSpatial.fit_sdem — Function
fit_sdem(W, X, y; varnames=nothing, method=ChebyshevApprox())

Fit the SDEM (Spatial Durbin Error Model) via concentrated ML: y = Xβ + WXθ + u, u = λWu + ε

Combines the SDM covariate structure with SEM error structure. LeSage & Pace (2009).

source

Regime Models

SpatialEconometrics.SpatialRegimeModels.fit_spatial_regime — Function
fit_spatial_regime(W, X, y, regimes; spatial_lag=true, varnames=nothing, method=ChebyshevApprox())

Fit a spatial regime model where coefficients vary across regimes: y = ρWy + Xr βr + ε (spatiallag=true) y = Xr βr + ε (spatiallag=false)

Each regime gets its own intercept and slope coefficients. Anselin (1988, 1990).

source
SpatialEconometrics.SpatialRegimeModels.skater_regimes — Function
skater_regimes(W, X, n_regimes; rng=Random.default_rng())

Spatially constrained clustering via SKATER-like minimum spanning tree partitioning. Returns an ExogenousRegimes assignment with n_regimes contiguous groups.

Assunção et al. (2006) "Efficient regionalization techniques for socio‐economic geographical units using minimum spanning trees."
