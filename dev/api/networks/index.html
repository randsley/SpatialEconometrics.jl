Spatial Econometrics for Networks

API reference for SpatialNetworks. See Networks for the discussion.

Module

SpatialEconometrics.SpatialNetworks — Module
SpatialNetworks

Spatial econometrics on networks rather than on geography.

Everything else in this package builds W from distance: knn_weights, distance_weights, band_weights. Here W comes from a graph — trade links, friendships, supply chains, citations — and the econometrics changes with it in one specific way that matters more than the construction does.

In a geographic model, y = ρWy + Xβ + WXθ + ε is identified because distance decays: a unit's neighbours and its neighbours' neighbours are different sets. On a network that is not automatic. Bramoullé, Djebbari and Fortin (2009) show that the endogenous effect β and the contextual effect δ are separately identified if and only if I, G and G² are linearly independent, and that this fails exactly on the structure applied work reaches for first: interaction in equal-sized groups. That is Manski's (1993) reflection problem, and it is an identification failure, so no quantity of data repairs it.

So the centre of this module is peer_identification, which answers that question mechanically before anything is estimated, and fit_peer_effects, which refuses to report a peer effect it cannot identify.

References

  • Bramoullé, Y., Djebbari, H. & Fortin, B. (2009). Identification of peer effects through social networks. Journal of Econometrics, 150(1), 41–55.
  • Manski, C. F. (1993). Identification of endogenous social effects: the reflection problem. Review of Economic Studies, 60(3), 531–542.
  • Leenders, R. T. A. J. (2002). Modeling social influence through network autocorrelation: constructing the weight matrix. Social Networks, 24(1), 21–47.
  • Lee, L. F. & Liu, X. (2010). Efficient GMM estimation of high order spatial autoregressive models with autoregressive disturbances. Econometric Theory, 26(1), 187–230.

Weight construction

SpatialEconometrics.SpatialNetworks.network_weights — Function
network_weights(A; normalize = :row, allow_self = false) -> SparseMatrixCSC

Interaction matrix from a network adjacency matrix.

A may be dense or sparse, square, symmetric (an undirected graph) or not (a directed one — citations, trade flows, who-follows-whom). Entries may be 0/1 or arbitrary non-negative strengths; Leenders (2002) is a sustained argument that the choice of entries is the model of social influence, not a preliminary to it, so nothing is assumed about them here beyond non-negativity.

Keywords

  • normalize: :row (default) divides each row by its sum, making Gy a neighbourhood average and bounding the interaction parameter inside (-1, 1); :none leaves the entries alone.
  • allow_self: by default a non-zero diagonal is an error, because a self-link makes Gy depend on yᵢ directly and the interaction parameter stops meaning what the model says it means. Pass true to keep it, or set the diagonal to zero yourself.

Isolates

Rows with no links stay all-zero rather than becoming NaN. This is deliberate and networks need it — a geographic W rarely has isolates and a social one usually does. But note that the second half of Bramoullé, Djebbari and Fortin's Proposition 1 (the non-identification half) is stated for networks with no isolated individual, so peer_identification reports the isolate count and withholds that half of the verdict when any are present.

Examples

A = sparse([0 1 1; 1 0 0; 1 0 0])
G = network_weights(A)             # row-standardised, undirected

See also group_weights, peer_identification.

source
network_weights(edges, n; directed = false, normalize = :row, allow_self = false)

Interaction matrix from an edge list.

edges is a vector of (i, j) pairs or (i, j, w) triples; n is the number of units, which must be given because isolates do not appear in an edge list and would otherwise be silently dropped. With directed = false each edge is entered both ways.

Duplicate edges are summed before normalisation, which matches the multigraph reading (two links are twice the exposure).

Examples

G = network_weights([(1, 2), (1, 3), (4, 5)], 6)   # unit 6 is an isolate

SpatialEconometrics.SpatialNetworks.group_weights — Function
group_weights(sizes; include_self = false, normalize = true) -> SparseMatrixCSC

Block-diagonal interaction matrix for interaction in groups: everyone in a group is affected by everyone else in it, and by nobody outside.

sizes gives the group sizes, so group_weights([4, 4, 4]) is three classrooms of four. This is the structure the peer-effects literature argues about, and the two conventions are not interchangeable:

  • include_self = false (default) is Moffitt's (2001) and Lee's (2007) convention — the group mean excludes i, so Gᵢⱼ = 1/(s-1) for j ≠ i in the group. Then G² = I/(s-1) + ((s-2)/(s-1))G within a block, so equal group sizes make I, G, G² dependent and identification fails — but unequal sizes break the dependence and it succeeds.
  • include_self = true is Manski's (1993) convention — the mean includes i. Then G² = G exactly, whatever the sizes are, and social effects are never identified. This is the reflection problem in its original form.

That contrast is the cheapest demonstration of why peer_identification exists, and both cases are pinned as tests.

normalize = false returns the unstandardised adjacency instead.

Examples

peer_identification(group_weights([5, 5, 5])).identified        # false
peer_identification(group_weights([4, 5, 6])).identified        # true
peer_identification(group_weights([4, 5, 6]; include_self = true)).identified  # false

Identification

SpatialEconometrics.SpatialNetworks.PeerIdentification — Type
PeerIdentification

Verdict on whether the endogenous and contextual peer effects are separately identified on a given network, as returned by peer_identification.

Fields

  • identified: the verdict. See the caveat under isolates below.
  • rank, required: the rank of [vec(I) vec(G) vec(G²)], and the rank Bramoullé, Djebbari and Fortin require — 3 without fixed effects (their Proposition 1), 4 with them, where the matrix is extended by vec(G³) (their Proposition 4).
  • svals: the singular values of that matrix, descending.
  • gap: svals[required] / svals[1] — the relative size of the singular value that decided the call. A gap of 1e-14 is a degenerate network; a gap of 0.3 is a comfortable one; something like 1e-7 means the verdict is a judgement about tolerance and should not be leaned on.
  • fixed_effects: which proposition was applied.
  • isolates: units with no links. Proposition 1's identification half holds for an arbitrary G, but its non-identification half is stated only for networks without isolates, so when isolates > 0 and the rank is short, identified is false but conclusive is false too.
  • conclusive: whether the verdict rests on the published result or on its identification half alone.
  • diameter, connected: diameter of the underlying undirected graph, and whether it is connected. Their Corollary 1 says a diameter of 3 or more is sufficient for identification under network fixed effects. -1 when not computed.
  • instrument_rank, n_instruments: rank of the realised instrument block [G²X] (and G³X under fixed effects) in the sample. This is a different question — it is about whether the instruments have power here, not about whether the model is identified in population — and it is reported separately for that reason. -1 when no X was supplied.

SpatialEconometrics.SpatialNetworks.peer_identification — Function
peer_identification(G; fixed_effects = false, X = nothing,
                    tol = 1e-6, compute_diameter = size(G, 1) <= 1000)

Decide whether the endogenous peer effect β and the contextual effect δ in

y = αι + βGy + γx + δGx + ε

are separately identified on the network G, by Bramoullé, Djebbari and Fortin's (2009) rank condition.

Their Proposition 1: social effects are identified if I, G and G² are linearly independent; if those are linearly dependent and no individual is isolated, social effects are not identified. Their footnote 17 gives the check used here, in their words: vectorize each matrix, stack the columns, and verify whether the matrix formed by concatenating these stacked vectors has rank three.

With fixed_effects = true the model is their eq. (10), the structural equation after the within-local transformation (I - G) that sweeps out a network-level unobservable. Proposition 4 then requires I, G, G², G³ to be linearly independent — strictly more demanding, because, in their words, information has been lost to take into account the presence of correlated effects.

Why this is not a formality

The condition fails on the structures applied work uses most. Interaction in equal-sized groups gives rank 2, not 3. With the group mean taken over everyone including oneself it gives rank 2 whatever the sizes are, since then G² = G exactly. Under fixed effects, two distinct group sizes are not enough and three are needed; star and complete bipartite networks give G³ = G and fail. In every one of those cases a peer-effects regression still runs and still prints two coefficients.

The tolerance

tol is a relative tolerance on the singular values, defaulting to 1e-6. That default is measured rather than conventional: across the degenerate structures the paper names the largest spurious singular value observed was 1.97e-8, and across identified structures the smallest genuine one was 4.0e-3. The default sits between them with two orders of magnitude of margin on each side. gap reports where a given network fell, so a verdict that rests on the tolerance is visible rather than implied.

The instrument rank is a different question

Pass X to also get the rank of the realised instrument block. The rank condition above is about the population model and does not involve X at all. Instrument rank is about whether this sample has the variation to exploit it. Both can be informative; only the first is the theorem.

Examples

peer_identification(group_weights([5, 5, 5]))     # rank 2, not identified
peer_identification(group_weights([4, 5, 6]))     # rank 3, identified
peer_identification(group_weights([4, 5, 6]); fixed_effects = true)  # rank 4

See also fit_peer_effects, group_weights.

Peer effects

SpatialEconometrics.SpatialNetworks.PeerEffectsFit — Type
PeerEffectsFit

Estimated linear-in-means peer-effects model, as returned by fit_peer_effects.

Fields

  • beta: the endogenous effect — the response to peers' outcomes.
  • gamma, delta: own characteristics, and the contextual effect of peers' characteristics. Aligned with varnames.
  • alpha: the intercept, or nothing under fixed effects, where the within-local transformation sweeps it out.
  • coefs, ses, names: the full coefficient vector and its standard errors, in the order the table prints.
  • vcov_kind: :robust, :homoskedastic or :transform.
  • sargan, sargan_df, sargan_p: over-identification test. df is the rank of the instrument block less the number of parameters, not its column count: a redundant instrument column supplies no restriction, and on rigid group structures there is often one. df is zero — and the test uninformative — when the model is exactly identified.
  • social_multiplier: γₖβ + δₖ for each characteristic. Bramoullé, Djebbari and Fortin maintain γβ + δ ≠ 0 throughout; when it is zero the social effects cancel out of the reduced form and nothing is identified, so a value near zero undercuts the estimates regardless of their standard errors. With several characteristics it must hold for at least one.
  • first_stage_F: partial F of the excluded instruments on Gy, after the included regressors are partialled out. The identification condition is a population statement; this is whether this network has the variation to exploit it. It collapses as the network gets denser, because in a dense graph a unit's peers' peers are nearly everybody and G²x flattens towards a constant. Measured on Erdős–Rényi graphs at n = 300, the median falls from 36.5 at average degree 4.6 to 4.4 at average degree 60, while the spread of β̂ rises twenty-one-fold.
  • ident: the PeerIdentification computed before fitting.
  • residuals, fitted, n.

SpatialEconometrics.SpatialNetworks.fit_peer_effects — Function
fit_peer_effects(y, X, G; fixed_effects = false, vcov = :robust,
                 instrument_order = 2, varnames = nothing,
                 tol = 1e-6, check = true)

Estimate the linear-in-means peer-effects model

y = αι + βGy + γx + δGx + ε

by two-stage least squares, using Bramoullé, Djebbari and Fortin's (2009) instruments, after checking that the model is identified at all.

β is the endogenous effect and δ the contextual effect. Gy is endogenous by construction — i affects j and j affects i — and the instruments are the characteristics of peers' peers, G²x, which enter the reduced form but not the structural equation.

The identification check is not optional

peer_identification runs first. If the network fails the rank condition the fit throws, because what it would otherwise return is two coefficients that are not separately estimable: the regression succeeds, the standard errors look ordinary, and the split between β and δ is arbitrary. Pass check = false to override, which is occasionally legitimate — you may want the point estimates on a near-degenerate network while knowing exactly what they are worth — and never silent.

It cannot rescue an exactly degenerate network, and that is not a limitation of the override. Bramoullé, Djebbari and Fortin prove in their Appendix B that I, G, G² are linearly dependent if and only if E(Gy|x) is perfectly collinear with (ι, x, Gx) — so when identification fails the instrument block is genuinely collinear with the included regressors, the design is singular, and no estimate exists to report. The fit then throws from the design-rank guard instead, naming the instrument columns. Measured on equal-sized groups, the residual of E(Gy|x) on (ι, x, Gx) is 8.9e-16.

Keywords

  • fixed_effects: apply the within-local transformation (I - G) to sweep out a network-level unobservable correlated with x, the model of their Section 3. Costs the intercept and tightens the rank condition from 3 to
  • vcov: :robust (default) is the heteroskedasticity-robust 2SLS sandwich. Bramoullé, Djebbari and Fortin leave the error variance matrix unrestricted and explicitly do not impose homoskedasticity, so this is the default rather than an option. :homoskedastic is σ̂²(X̃'PX̃)⁻¹. :transform is for the fixed-effects case only and accounts for the correlation the transformation itself induces, Var((I-G)ε) = σ²(I-G)(I-G)'; it is the right answer when the underlying errors really are homoskedastic and the wrong one when they are not.
  • instrument_order: 2 (default) uses G²x, which is the instrument set in their empirical section. 3 adds G³x, buying over-identifying restrictions — hence a usable Sargan test — at the cost of weaker instruments.
  • check: see above.

Examples

G = network_weights(A)
fit = fit_peer_effects(y, X, G)
fit.beta                      # endogenous peer effect
fit.ident.gap                 # how comfortable the identification was

References

Bramoullé, Djebbari & Fortin (2009), eqs. (1), (10) and §4.

See also peer_identification, network_moran.

SpatialEconometrics.SpatialNetworks.network_moran — Function
network_moran(fit, W; kwargs...) -> MoranResult

Moran's I of a peer-effects fit's residuals against a weight matrix W, which need not be the interaction matrix the model was fitted on.

The useful case is passing a different W from the G used to fit: it asks whether dependence remains along some channel the model did not include — geography, say, after a social network has been controlled for. Passing the same G back asks whether the endogenous effect has absorbed the dependence it was meant to.

Keyword arguments are forwarded to moran_global, including inference, n_perm and rng.

SpatialEconometrics.SpatialNetworks.fit_multiplex_sar — Function
fit_multiplex_sar(y, X, Ws; channel_names = nothing, varnames = nothing,
                  rho_bound = 0.995, tol = 1e-9, maxiter = 200)

Fit

y = Σⱼ ρⱼ Wⱼ y + Xβ + ε

by concentrated maximum likelihood, where the Wⱼ are different interaction channels over the same units — trade and migration and shared ownership, say — rather than different lags of one network.

Each channel gets its own ρⱼ, so the fit answers which channel carries the dependence, which a single pooled W cannot. An intercept is added; do not include one in X.

How it is fitted

β and σ² are concentrated out at each trial ρ, leaving a J-dimensional profile maximised by coordinate ascent, each coordinate by the same Brent search the single-channel fit uses. log|I - Σρⱼ Wⱼ| is computed exactly by sparse LU at every evaluation: the Chebyshev approximation available for one W rests on precomputed traces of its powers and does not carry over to an arbitrary combination, so it is not offered here rather than offered and quietly wrong.

Standard errors come from the analytic information matrix, which generalises the single-channel one; with one channel this function reproduces fit_spatial(SAR, ...) to machine precision, and that is pinned as a test.

Stationarity

The parameter space is Σⱼ |ρⱼ| < rho_bound. With each Wⱼ row-standardised this is sufficient for I - Σρⱼ Wⱼ to be invertible, since the spectral radius of the combination is then at most Σ|ρⱼ|. It is sufficient and not necessary — some stationary points lie outside it — so a fit that lands against the boundary is reported with converged = false rather than silently accepted.

A caveat worth reading

Coordinate ascent is exact along each axis but can stall on a ridge, which is what a pair of strongly overlapping channels produces. channel_rank reports whether the channels are distinguishable as matrices at all, and convergence from several starting points is cheap insurance. The tests measure the gap against a dense grid search.

References

Lee, L. F. & Liu, X. (2010). Efficient GMM estimation of high order spatial autoregressive models with autoregressive disturbances. Econometric Theory, 26(1), 187–230.
