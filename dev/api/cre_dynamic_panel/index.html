Short-T Dynamic Panel with Correlated Random Effects

API reference for CREDynamicSpatialPanel. See Short-T Dynamic Panel (CRE) for the discussion, including the role of the assumed process start m.

Module

SpatialEconometrics.CREDynamicSpatialPanel — Module
CREDynamicSpatialPanel

Short-panel (fixed-T) spatial dynamic panel with correlated random effects, by Li & Yang's (2021) M-estimator:

\[y_t = ρy_{t-1} + λ_1W_1y_t + λ_2W_2y_{t-1} + X_tβ + Zγ + μ + α_t1_n + u_t,\quad u_t = λ_3W_3u_t + v_t,\quad μ = \bar Xπ + ε,\]

for t = 1, …, T, with X̄ the mean of X_0, …, X_T. The process started m periods before the first observed period, so y_0 is endogenous and the conditional QMLE is inconsistent with T fixed. The M-estimator solves the adjusted quasi-score (AQS): the conditional quasi-score with each biased component corrected by its expectation (Lemma 2.1). The corrections depend on the initial observations only through m.

This is the fixed-T counterpart of fit_dynamic_spatial_panel, whose Yu, de Jong & Lee bias correction is a large-T device.

The covariance is a sandwich whose middle is a corrected plug-in estimate of the variance of the adjusted score, adapted from Li, Meng & Yang (2026); it allows non-normal, but not heteroskedastic, errors. It is not Li & Yang's hybrid estimator.

References

Li, L., & Yang, Z. (2021). Spatial dynamic panel data models with correlated random effects. Journal of Econometrics, 221(2), 424–454.

Li, L., Meng, X., & Yang, Z. (2026). Dynamic spatial panel data models with fixed effects: alternative approaches and application. Spatial Economic Analysis, accepted.

Estimation

SpatialEconometrics.CREDynamicSpatialPanel.CREDynamicSpatialPanelModel — Type
CREDynamicSpatialPanelModel

A fit of the short-panel CRE spatial dynamic panel by fit_cre_dynamic_spatial_panel.

Fields

  • coef, coefnames: ψ = (β, σ²_v, φ, ρ, λ₁[, λ₂][, λ₃]), where β stacks the intercept, the time dummies, the coefficients on X_t, on Z and on X̄ (Mundlak's π), and φ = σ²_ε/σ²_v.
  • vcov: the sandwich Ĵ⁻¹Γ̂Ĵ⁻¹', with Ĵ = −∂S*/∂ψ' and Γ̂ the corrected plug-in estimate of Var(S*). It is valid for non-normal errors (it uses the estimated third and fourth moments of ε and v), not for heteroskedastic ones. The construction adapts the corrected plug-in estimator of Li, Meng & Yang (2026) for the fixed-effects model; it is not Li & Yang's (2021) hybrid estimator, whose details are in a supplement this package does not hold.
  • vcov_hessian: Ĵ⁻¹ from the AQS Jacobian alone. Not robust: it is Var(ψ̂) only when the AQS is an information-equal score, which it is not when m > 0. Kept for comparison.
  • moments: the estimated (μ3ε, μ4ε, μ3v, μ4v) used by vcov.
  • cqmle: the conditional QMLE of ψ, which is inconsistent with T fixed when y₀ is endogenous. Kept because it is the starting value and the comparison the paper reports.
  • m: the assumed process start, m periods before period 0.
  • residuals: the composite errors e = ε ⊗ 1 + B₃⁻¹v, stacked like y.
  • loglik: the conditional quasi log-likelihood (2.4) at the M-estimate, which does not maximise it.
  • converged, iterations, score_norm: the root solver's report.
  • n, T, time_effects.

SpatialEconometrics.CREDynamicSpatialPanel.fit_cre_dynamic_spatial_panel — Function
fit_cre_dynamic_spatial_panel(y, X, Z, W1, N, T_total; m,
                              W2 = W1, W3 = W1, time_effects = true,
                              varnames = nothing, zvarnames = nothing,
                              max_iter = 100, tol = 1e-10)

Li & Yang's (2021) M-estimator for the short-panel spatial dynamic panel with correlated random effects (see CREDynamicSpatialPanel for the model).

Data

y and X are stacked as in fit_dynamic_spatial_panel: N units within each of T_total = T + 1 periods, period 0 first. Period 0 supplies y₀ and enters the Mundlak mean X̄; estimation uses periods 1..T. Z is an N×q matrix of time-invariant regressors without an intercept, or nothing. A regressor in X that does not vary over time duplicates its own mean and is refused; put it in Z.

Options

  • m (required): the process started m ≥ 0 periods before period 0. m = 0 means y₀ is exogenous, and then the M-estimator is the conditional QMLE. There is no default, because the estimator depends on it.
  • W2, W3: the space-time lag and spatial error weights; nothing drops λ₂ or λ₃ together with its estimating equation.
  • time_effects: include α_t as T − 1 period dummies.
  • compute_cqmle: also compute the conditional QMLE, kept in cqmle (NaNs if its optimiser fails). It is inconsistent when m > 0; it is there for comparison.
  • max_iter, tol: the root solver's limits, with tol on ‖S*‖/(nT).

Solving

The adjusted score can have more than one root, so the solver starts from a consistent estimate (2SLS on first differences) rather than from the conditional QMLE. It is Levenberg–Marquardt in (log φ, ρ, λ), with the φ equation taken in log φ because φ = ∞ is a false root of the raw φ score. If no root is reached, the solver is run once more from the same start with φ = 1; if that fails too, the fit throws.

Returns

A CREDynamicSpatialPanelModel. vcov is the sandwich with the corrected plug-in Var(S*); vcov_hessian is the inverse Jacobian alone, which is not a valid covariance when m > 0.
