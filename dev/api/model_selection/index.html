Model Selection

Information criteria and tests for choosing between specifications.

SpatialEconometrics.SpatialModelSelection.CommonFactorTestResult — Type
CommonFactorTestResult

Test of the common-factor restriction, returned by common_factor_test.

Fields: stat, df, p_value, reject.

A Spatial Durbin model reduces to a spatial error model exactly when theta = -rho * beta. Failing to reject means the simpler error specification is adequate; rejecting means the Durbin terms carry information the error model cannot represent.

See also SDM, fit_spatial_error.

source
SpatialEconometrics.SpatialModelSelection.LRTestResult — Type
LRTestResult

Likelihood-ratio test between nested models, returned by lr_test.

Fields: stat, df, p_value, and both log-likelihoods (ll_restricted, ll_unrestricted).

Warning

Valid only when one model genuinely nests the other and both were fitted to the same data by maximum likelihood. For non-nested comparisons use vuong_test.

source
SpatialEconometrics.SpatialModelSelection.VuongTestResult — Type
VuongTestResult

Vuong test between two non-nested models, returned by vuong_test.

Fields: stat, p_value, aic_correction, and preference, which is :model1, :model2 or :indistinguishable.

Use this where lr_test does not apply — comparing a spatial lag against a spatial error specification, for instance, since neither nests the other. :indistinguishable is a genuine outcome, not a failure: the data may simply not separate the two.

source
SpatialEconometrics.SpatialModelSelection.WaldTestResult — Type
WaldTestResult

Wald test of a linear restriction R*beta = r, returned by wald_test.

Fields: stat, df, p_value. Needs only the fitted model's coefficients and covariance, so unlike lr_test it does not require refitting under the restriction.

source
SpatialEconometrics.SpatialModelSelection.common_factor_test — Function
common_factor_test(coef_beta, coef_theta, rho, vcov_full)

Tests whether SDM simplifies to SEM, i.e. H₀: θ + ρβ = 0.

  • coef_beta: vector of K slope coefficients (excluding intercept)
  • coef_theta: vector of K spatial lag coefficients (WX terms)
  • rho: spatial autoregressive parameter
  • vcov_full: full variance-covariance matrix of [β; θ; ρ]

Uses the Wald test formulation from Burridge (1981).
